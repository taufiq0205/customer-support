# Support Insight

Local, single-user support chat analysis for the Photobook support lead.

## Local setup

- Node.js 20.9 or newer
- `npm ci`
- `npm run dev`

Open <http://127.0.0.1:3000>. The app and API bind to `127.0.0.1`.
The starter page is `/` and the health endpoint is `/api/health`.

Zaapi inputs, database files, sidecars, and local keys are ignored by Git.
Use only synthetic fixture data while developing.
